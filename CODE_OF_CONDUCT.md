# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful, harassment-free community. Be constructive, assume good faith, respect differing viewpoints, and focus criticism on ideas and implementation.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, and publishing private information. Project maintainers may remove content or restrict participation for conduct that violates this policy.

Report conduct concerns privately to the project maintainers using the contact method listed in the repository profile.
